# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful, assume good faith, and keep discussion about the work. Report
concerns privately to the maintainers through GitHub's private reporting channel
described in [SECURITY.md](SECURITY.md); maintainers will review and respond
confidentially.
